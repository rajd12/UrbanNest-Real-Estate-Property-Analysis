 UrbanNest – Real Estate Property Analysis Dashboard

📌 Project Overview

UrbanNest is an interactive Real Estate Property Analysis Dashboard developed using Microsoft Power BI. The project focuses on analyzing property inventory, sales performance, property types, pricing trends, and city-wise distribution to generate meaningful business insights.

The dashboard helps users understand real estate market trends and make data-driven decisions through interactive visualizations and KPI indicators.

🎯 Project Objectives

* Analyze total property inventory and availability.
* Monitor sold, booked, and available properties.
* Compare different property types.
* Understand city-wise property distribution.
* Analyze average property values across cities.
* Study BHK-wise property inventory.
* Identify residential and commercial property segments.

🛠️ Tools & Technologies

* Microsoft Power BI – Dashboard development and visualization.
* DAX – Calculations and KPI measures.
* Power Query – Data cleaning and transformation.
* Microsoft Excel – Data source and preparation.

📊 Dashboard Features

1. Key Performance Indicators (KPIs)

* Total Properties
* Available Properties
* Booked Properties
* Sold Properties
* Average Property Value

2. Interactive Visualizations

Visualization	Chart Type
Property Status Distribution	Donut Chart
Property Type Comparison	Clustered Column Chart
Property Inventory by City	Bar Chart
Average Property Value by City	Column Chart
Property Segment Distribution	Pie Chart
BHK-wise Inventory Analysis	Column Chart

3. Interactive Filters (Slicers)

* City
* Property Type
* Property Status
* BHK

These filters allow users to explore property data dynamically.

💡 Key Insights

The dashboard helps identify:

* Property availability and sales distribution.
* Cities with the highest property inventory.
* Property types with the highest representation.
* Differences in average property values across cities.
* Distribution of residential and commercial properties.
* Demand patterns across different BHK configurations.
